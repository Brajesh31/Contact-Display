# 🤝 Code of Conduct

## 🌱 Our commitment

Participants in the Contact Display project are expected to contribute to a respectful, constructive, and inclusive environment. This policy applies to issues, discussions, pull requests, reviews, and other project spaces.

## ✅ Expected behavior

- Communicate respectfully and assume good intent.
- Provide actionable, technically focused feedback.
- Respect differing experience levels and perspectives.
- Accept constructive criticism gracefully.
- Protect private information and never publish another person's contact data.
- Keep discussions relevant to the project.
- Disclose security concerns responsibly rather than publishing exploit details.

## 🚫 Unacceptable behavior

- Harassment, discriminatory language, threats, or personal attacks.
- Publishing private contact information, credentials, or other sensitive data.
- Spam, impersonation, or deliberate disruption.
- Trolling, intimidation, or repeated bad-faith participation.
- Submitting malicious code, hidden payloads, or deceptive changes.
- Misrepresenting test results, features, ownership, or security claims.

## 🧭 Enforcement

Project maintainers may remove content, edit or close discussions, reject contributions, temporarily restrict participation, or block accounts depending on severity and recurrence.

## 📣 Reporting

Report conduct concerns privately to the repository maintainer through the GitHub profile contact route: [Brajesh31](https://github.com/Brajesh31). Do not include sensitive personal information in public issues.

Reports should include:
1. A concise description of the concern.
2. Relevant links or timestamps.
3. Any context needed to assess the incident.
4. Whether immediate action is required.

## 🔎 Review process

Maintainers will review reports as promptly as practical, handle them discreetly, gather relevant context, and determine proportionate action. This document does not promise a fixed response time.

## 📚 Scope

This policy applies to project spaces and public behavior that materially affects project participants. It is not a substitute for GitHub's own policies or applicable law.
