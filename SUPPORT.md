## 🐛 Reporting a problem

Open a GitHub issue with:
- A descriptive title.
- Browser and operating-system versions.
- Steps to reproduce.
- Expected and actual behavior.
- Console errors with personal data removed.
- Screenshots only after removing private contact information.

## 💬 Questions and feature ideas

Use GitHub Discussions if enabled, or open an appropriately labeled issue. Search existing conversations first.

## 🔐 Privacy reminder

Never attach browser-storage exports, real contact lists, phone numbers, access tokens, or other personal information to public issues.

## ⏱️ Response expectations

Support is maintained on a best-effort basis. No guaranteed response time or commercial support arrangement is offered.
