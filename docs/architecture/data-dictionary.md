# 📖 Contact Data Dictionary

| Field | Meaning | Source-level usage | Caveat |
|---|---|---|---|
| `id` | Record key | Lookup, route param, update/delete. | Generated by helper. |
| `createdAt` | Creation timestamp | Sorting. | Numeric timestamp. |
| `first`, `last` | Name fields | Display and search. | Optional. |
| `avatar` | Avatar URL | Image source. | External URL possible. |
| `website` | Website text | Rendered as HTTPS link. | User-provided. |
| `number` | Phone number | Detail display and form field. | Form uses a fixed pattern. |
| `notes` | Free-form note | Detail display and edit. | May contain personal information. |
| `favorite` | Favorite marker | Star display/toggle. | Form string is converted to boolean. |

The shape is inferred from the helper and UI fields, not a formal schema contract.
