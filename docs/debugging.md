# 🐞 Debugging

| Symptom | Diagnostic |
|---|---|
| Contact list empty | Inspect browser storage and verify current origin/profile. |
| Search returns no results | Check the query and stored first/last fields. |
| Contact route fails | Confirm the ID exists in the stored collection. |
| Changes disappear | Confirm the same browser profile and origin are used. |
| Vite fails to start | Check runtime compatibility and npm install output. |
| Build fails | Capture full terminal output and identify the failing module/dependency. |

## 🔐 Privacy
Redact names, phone numbers, notes, avatar URLs containing tokens, and other private contact data before sharing logs or screenshots.
