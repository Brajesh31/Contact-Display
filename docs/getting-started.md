# 👋 Getting Started

1. Clone the repository.
2. Install locked dependencies using `npm ci`.
3. Start Vite using `npm run dev`.
4. Open the local URL printed in the terminal.
5. Use New from the list screen to start a contact.
6. Complete the edit form and save.
7. Open the contact to inspect details and favorite state.
8. Use Edit or Delete to explore the corresponding actions.

Contact persistence is browser-local. Use the same origin and browser profile to access the same local collection.
