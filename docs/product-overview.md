# 👤 Product Overview

## 🎯 Purpose

Contact Display is a browser-based contact organizer. It demonstrates a contact list and CRUD-style interaction using a React interface, route loaders/actions, and browser-managed persistence.

## 👥 Intended users

| User group | Need | Supported workflow |
|---|---|---|
| Individual user | Keep a small personal contact list in one browser profile. | Create, view, edit, search, favorite, and delete. |
| Learner / developer | Study a React Router data-router example. | Inspect routes, loaders, actions, and data helpers. |
| Maintainer | Preserve and document the current application. | Run Vite scripts and review source modules. |

## ✅ Product capabilities

The inspected source supports:
- Listing saved contact records.
- Searching by first and last name.
- Creating an empty contact record and navigating to its edit screen.
- Viewing a contact.
- Updating contact fields.
- Toggling a favorite flag.
- Deleting a contact after browser confirmation.
- Saving records through localForage.

## 🧱 Product boundary

The root application does not show a remote account system, server API, cloud synchronization, shared team address book, or database service. The app's persisted data is browser-side.

## 🧾 Contact record model

The data helpers demonstrate these fields:

| Field | Observed purpose | Notes |
|---|---|---|
| `id` | Record identifier | Generated by the data helper. |
| `createdAt` | Creation timestamp | Stored as a numeric timestamp. |
| `first` | First name | Optional in the UI. |
| `last` | Last name | Optional in the UI. |
| `avatar` | Avatar image URL | Optional. |
| `website` | Website text | Rendered as an HTTPS link. |
| `number` | Phone number text | Edit form has a specific 3-3-4 pattern. |
| `notes` | Free-form notes | Optional. |
| `favorite` | Favorite flag | Used for the star toggle. |

This is an observed shape, not a formal database schema. See [data architecture](architecture/data-architecture.md).

## ⚠️ Product limitations

- Data remains in the browser storage context.
- No remote synchronization or multi-device sharing is documented.
- No sign-in or server-side authorization was found.
- Browser data deletion, browser profile changes, and origin changes may affect retained contacts.
- The current source contains initialization and delete-helper inconsistencies listed in [known issues](known-issues.md).
