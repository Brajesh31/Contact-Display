# ⌨️ Commands Reference

Commands are taken from the inspected root `package.json`.

| Command | Purpose |
|---|---|
| `npm ci` | Install dependencies from lockfile. |
| `npm run dev` | Start Vite development server. |
| `npm run build` | Build production assets. |
| `npm run preview` | Preview production build locally. |
| `npm run lint` | Run configured ESLint command. |

The root manifest does not declare `npm start`, backend start, database seed/migrate, or test scripts.
