# 🚀 Installation

## Prerequisites
- Git
- Node.js compatible with Vite 5
- npm

## Steps
```bash
git clone https://github.com/Brajesh31/Contact-Display.git
cd Contact-Display
npm ci
npm run dev
```

Open the URL printed by Vite. No MongoDB service, Express server, or separate backend setup is required by the inspected root package.

## Production build
```bash
npm run build
npm run preview
```

The default Vite output is `dist/` unless the preserved Vite configuration changes it.
