# 👩‍💻 Developer Guide

Start by reading:
1. `src/main.jsx` for bootstrap and routing.
2. `src/routes/root.jsx` for the application shell and contact list.
3. `src/contacts.js` for persistence and CRUD.
4. `src/routes/contact.jsx` for details and favorites.
5. `src/routes/edit.jsx` for the edit form.
6. `src/routes/destroy.jsx` for deletion.

Use [installation](installation.md) and [local development](local-development.md) to run the application. Run `npm run lint` and `npm run build` when appropriate; record actual results.

Preserve application code during documentation-only work. Record suspected source defects with evidence and request a separate code-change authorization.
