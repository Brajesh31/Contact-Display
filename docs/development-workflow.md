# 🔁 Development Workflow

1. Read the README and architecture guide.
2. Check current issues and repository state.
3. Create a focused branch.
4. Update related documentation indexes and cross-links together.
5. Run documentation validators.
6. Run existing npm lint/build checks when warranted.
7. Review the diff to ensure application files remain unchanged.
8. Submit a PR with scope, evidence, and limitations.

## Documentation-only policy
The current repository enhancement policy preserves application source, styles, dependencies, lockfiles, and build configuration. Record code concerns separately and request authorization before fixing them.
