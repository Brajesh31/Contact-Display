# 📖 Project Glossary

| Term | Meaning in this repository |
|---|---|
| Contact | A JavaScript record representing a person or organization entry. |
| Contact collection | Array stored under localForage key `contacts`. |
| localForage | Browser storage abstraction used by the contact helper. |
| Data router | React Router configuration using route loaders and actions. |
| Loader | Route function that retrieves data before rendering a route. |
| Action | Route function that handles submitted form data or mutations. |
| Fetcher | React Router API used for submitting data without a full navigation. |
| Route parameter | Dynamic URL value such as `:contactId`. |
| Origin | Scheme, host, and port boundary used by the browser for storage isolation. |
| Browser profile | Local browser user profile and its site data. |
| Build artifact | Generated production output created by Vite. |
| Static source review | Inspection of source files without executing application behavior. |
| Runtime verification | Executing the app or tests and recording environment/results. |
| Documentation-only change | Repository update that avoids application source, dependencies, and build/runtime configuration. |
