# 🧰 Maintenance

| Cadence | Activity | Evidence |
|---|---|---|
| Each change | Review docs links and referenced paths. | Validator output. |
| Each release | Run lint/build scripts. | CI/local logs. |
| Regularly | Review dependencies and advisories. | Dependency review record. |
| Regularly | Review vendored Bootstrap notices. | Vendor review record. |
| On UI change | Update route/page docs. | Route inventory update. |
| On architecture change | Update diagrams/decision records. | Updated architecture docs. |
| After incident | Record response and lessons. | Incident report. |

Preserve application code during documentation-only maintenance. Raise source-level issues separately for authorization.
