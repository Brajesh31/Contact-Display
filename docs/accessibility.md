# ♿ Accessibility

## 🎯 Review target
Use WCAG 2.2 AA as a target where relevant. This is not a verified compliance claim.

| Area | Review |
|---|---|
| Semantics | Headings, labels, landmarks, button names. |
| Keyboard | Reach navigation and form controls without a pointer. |
| Focus | Visible focus and predictable focus after navigation. |
| Forms | Persistent labels and announced validation errors. |
| Screen readers | Contact name, favorite state, loading state. |
| Contrast | Text, borders, and interaction states. |
| Motion | Reduced-motion preferences where animation exists. |
| Zoom/reflow | Narrow viewports and text enlargement. |
| Destructive actions | Clear deletion intent and confirmation. |

Record environment, browser, assistive technology, findings, and remediation evidence. No audit or conformance result is claimed.
