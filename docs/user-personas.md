# 👥 User Personas

These are lightweight usage personas inferred from the application's available capabilities, not research-backed demographic profiles.

| Persona | Goal | Relevant functionality | Limitation |
|---|---|---|---|
| Personal organizer | Keep a contact list in one browser. | Add, view, edit, search, favorite, delete. | No account-based sync found. |
| Learner | Understand React Router data APIs. | Routes, loaders, actions, forms, fetcher. | Not a production backend reference architecture. |
| Maintainer | Keep the app documented and buildable. | npm scripts, source map, docs validation. | No test script found in manifest. |

## User needs
- Understand where records are stored.
- Know what happens when data is deleted.
- Find an existing contact quickly.
- Avoid accidentally exposing personal contact details while asking for support.
